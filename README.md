# 🚀 CodeSolve AI

CodeSolve AI is an intelligent, AI-powered coding assistant developed during the **Technov8 National-Level Hackathon** organized by Ainnov8 DGI at Dronacharya Group of Institutions on March 30, 2025.

Out of **192+ teams** from all over India, this project secured a **Top 10 finalist spot** — built **solo** in a team-based hackathon!

---

## 🧠 What is CodeSolve AI?

CodeSolve AI is designed to **enhance the way developers solve coding problems**. It offers:
- **Contextual support**
- **Accurate solutions**
- **Intelligent code suggestions**
- **Real-time feedback**

---

## 💡 Features

- 🤖 **AI-Powered Assistant**  
  Integrated with **Google Gemini API** to provide intelligent, context-aware programming support.

- 🧠 **Contextual Memory**  
  Tackles common issues like incomplete or contextless answers from traditional AI tools.

- 🐞 **Debugging Assistance**  
  Helps identify and fix bugs in user-submitted code snippets.

- ⚡ **Real-Time Code Generation**  
  Provides real-time suggestions and explanations for code-related problems.

- 🧼 **Clean UI/UX**  
  Built with modern HTML5, CSS3, and JavaScript for a smooth and responsive interface.

- 📄 **Markdown Rendering**  
  Utilizes `markdown2` to display formatted AI-generated content beautifully.

## 🏁 Getting Started

### 📋 Prerequisites

- Python 3.7+
- Google Gemini API Key
- Flask installed

### 🔧 Installation

```bash
git clone https://github.com/your-username/CodeSolveAI.git
cd CodeSolveAI
```
🚀 Run the App
```bash
python app.py
```
